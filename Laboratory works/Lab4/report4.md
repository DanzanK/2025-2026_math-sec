# Введение

В данной лабораторной работе реализуются алгоритмы вычисления наибольшего общего делителя (НОД) для двух целых чисел: алгоритм Евклида, бинарный алгоритм Евклида (Стейна), расширенный алгоритм Евклида и расширенный бинарный алгоритм Евклида. # Теоретические сведения

## Наибольший общий делитель

НОД двух целых чисел $a$ и $b$ — это наибольшее целое число $d$, делящее оба числа без остатка.

Ключевое свойство (лемма Евклида): если $a = qb + r$, то
$$
\gcd(a,b) = \gcd(b,r).
$$
Отсюда следует классический алгоритм Евклида: заменять пару $(a,b)$ на $(b, a \bmod b)$ до тех пор, пока остаток не станет равен нулю.

## Алгоритм Евклида

На каждом шаге вычисляется остаток $r = a \bmod b$, затем выполняется переход $(a,b) \leftarrow (b,r)$. Последний ненулевой остаток и есть НОД.

## Бинарный алгоритм Евклида (Стейна)

Алгоритм использует свойства:

- если $a$ и $b$ чётные, то $\gcd(a,b)=2\cdot\gcd(a/2,b/2)$;
- если $a$ чётное, $b$ нечётное, то $\gcd(a,b)=\gcd(a/2,b)$;
- если $a$ и $b$ нечётные, то $\gcd(a,b)=\gcd(|a-b|, \min(a,b))$.

Преимущество — замена деления на операции деления на 2 (битовые сдвиги) и вычитания.

## Расширенный алгоритм Евклида

Помимо $d=\gcd(a,b)$ алгоритм находит $x$ и $y$, такие что:
$$
ax + by = d.
$$
Коэффициенты вычисляются вместе с остатками, поддерживая инвариант представления текущего остатка как линейной комбинации $a$ и $b$.

## Расширенный бинарный алгоритм Евклида

Это расширение бинарного алгоритма Евклида, где дополнительно поддерживаются коэффициенты линейных комбинаций для текущих значений (инварианты вида $u=Aa+Bb$, $v=Ca+Db$). При делении на 2 выполняются корректировки коэффициентов, чтобы сохранялась целочисленность.

Программная реализация алгоритма Евклида показана на [Листинге №1](#euclid).


### Листинг 1 — Алгоритм Евклида{#euclid}


```python
def euclidean_gcd(a,b):
    r_prev, r_curr = a,b
    
    while r_curr !=0:
        r_next = r_prev % r_curr
        r_prev = r_curr
        r_curr = r_next

    d = r_prev
    return d

vala = 12345
valb = [24690, 54321, 12541]
for val in valb:
    print(f"GCD({vala}, {val}) = {euclidean_gcd(vala, val)}")
```

### Листинг 2 — Бинарный алгоритм Евклида (Стейна) {#binary}


```python
def binareuc_gcd(a,b):
    g = 1

    while a%2 == 0 and b%2 ==0:
        a //=2
        b //= 2
        g *= 2

    u, v = a, b

    while u != 0:
        while u% 2 ==0:
            u //= 2
        while v% 2 ==0:
            v //= 2
        if u >= v:
            u = u-v
        else:
            v = v-u

    d = g * v

    return d 

vala = 12345
valb = [24690, 54321, 12541]
for val in valb:
    print(f"GCD({vala}, {val}) = {binareuc_gcd(vala, val)}")
```

Программная реализация расширенного алгоритма Евклида показана на [Листинге №3](#egcd).


### Листинг 3 — Расширенный алгоритм Евклида {#egcd}

```python
def extendedeuc_gcd(a,b):
    r_prev, r_curr = a,b
    x_prev, x_curr = 1, 0
    y_prev, y_curr = 0, 1

    while r_curr !=0:
        q = r_prev // r_curr
        r_next = r_prev % r_curr
        x_next = x_prev - q * x_curr
        y_next = y_prev - q * y_curr

        r_prev, r_curr = r_curr, r_next
        x_prev, x_curr = x_curr, x_next
        y_prev, y_curr = y_curr, y_next

    d, x, y = r_prev, x_prev, y_prev
    return d, x, y_curr

d1, x1, y1 = extendedeuc_gcd(105,91)
d2, x2, y2 = extendedeuc_gcd(154, d1)
print(f"GDC(105,91) = {d1, x1, y1}")
print(f"final GDC(154,7) = {d2, x2, y2}")
```

```python
def extendbineuc_gcd(a,b):
    g = 1
    while a% 2 ==0 and b%2 == 0:
        a //=2
        b //= 2
        g *= 2
    
    u, v = a, b
    A, B = 1, 0
    C, D = 0, 1

    while u != 0:
        while u % 2==0:
            u //=2
            if A % 2 == 0 and B % 2 == 0:
                A //= 2
                B //= 2
            else:
                A = (A + b) // 2
                B = (B - a) // 2
            print("v: " + str(v))

        while v%2==0:
            v //= 2
            if C % 2 == 0 and D % 2 == 0:
                C //= 2
                D //= 2
            else:
                C = (C+b) // 2
                D = (D-a) // 2
            print("u: " + str(u))

        if u >= v:
            u = u- v
            A = A - C
            B = B - D
        else:
            v = v - u
            C = C - A
            D = D - B
    d = g * v
    x = C
    y = D
    return d, x, y

dbin,xbin,ybin = extendbineuc_gcd(105, 91)
print(f"GDC(105,91) = {dbin,xbin,ybin}")
```
